How we handle feedback

  1. 1
    You submit — Post to GitHub Discussions or Issues using one of the links above. The pre-filled templates make it fast.
  2. 2
    We triage — Every submission gets a response within 5 business days. We label, clarify if needed, and link related requests.
  3. 3
    Community upvotes — Other users can +1 and comment on open ideas. High-signal ideas move up the roadmap.
  4. 4
    We ship or explain — When we build it, we close the thread with a link to the release. When we decline, we explain why.
