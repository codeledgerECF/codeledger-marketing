CodeLedger v0.10.83 runtime downloads withdrawn

We withdrew the runtime downloads after a release review identified an issue with the contents of the distributed builds. Fresh installs on Mac, Linux, and Windows may be unable to start CodeLedger or connect over MCP.

An installation that already has a local runtime may continue to work. The v0.10.82 runtime downloads were also withdrawn.

We’ll post replacement availability after qualification on the GitHub release notice.
