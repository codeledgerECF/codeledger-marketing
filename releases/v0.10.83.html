CodeLedger v0.10.83

When a coding agent names a behavior, you still need to find the implementation, the test, and the revision. CodeLedger gives Claude Code and Codex task-scoped repository context through MCP, with source windows you can check.

Download

  • Mac and Linux bootstrap ZIP for Apple Silicon macOS and Linux x64. The wrapper may fetch the native runtime.
  • Apple Silicon macOS native ZIP. The runtime is bundled. Gatekeeper may need internet access.
  • Windows x64 Node standalone and third-party notices. Node 24 was used for qualification.

Compare your download with the SHA-256 manifest. The release page lists the native binaries and installation choices.

Try one task

  1. On a supported native platform, you can also install with npm install -g @codeledger/cli@0.10.83.
  2. In your checkout, run codeledger ready --task "Find the implementation and test for the behavior I am changing". Review generated guidance with git status --short.
  3. Point Claude Code or Codex at this checkout through MCP and ask it to call get_activation_payload. Ask for the implementation, the test, and the revision.

Context stays separate across linked worktrees. Reactivate after moving HEAD to refresh the evidence. PR advice in observe mode can point to nearby tests and gaps without blocking a merge.
